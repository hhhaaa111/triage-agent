## 2. 深入分析：`CalibratedClassifierCV` 与 `TfidfVectorizer`

**解决什么子任务。** `TfidfVectorizer` 把变长文本变成定长稀疏向量；`CalibratedClassifierCV`
把线性 SVM 的决策间隔转换成可比较的概率，使"置信度阈值"这件事有物理意义。

**输入输出。** 前者输入字符串列表，输出 `(n_docs, n_features)` 的稀疏矩阵；后者输入该矩阵与标签，
输出每个类别的概率向量，维度等于类别数（本项目 20）。

**依赖与权限。** 纯本地计算，不依赖外部服务、不需要网络与密钥。20 Newsgroups 的下载步骤需要网络，
但下载后可完全离线运行。

**限制。** 概率校准采用 Sigmoid 与 3 折内部交叉验证，训练时间约为裸 SVM 的 2–3 倍；校准后的概率
并非严格概率，只是"可比分数"，在分布偏移时仍会高估置信度。TF-IDF 丢失词序，反讽、否定转移这类
依赖语序的语义无法表达；词表规模随 `min_df` 变化，过小会引入大量只出现一两次的噪声词。

**如何核验。** 一是对照实验：同一特征下比较朴素贝叶斯、逻辑回归、裸 SVM 与校准 SVM 的宏 F1，
确认校准没有损害分类效果（0.6930 对 0.6888）。二是行为测试：`tests/test_agent.py` 覆盖空输入、
过短输入、领域外输入、超长截断与频道路由，确认异常走的是复核路径而不是抛出异常。三是阈值扫描：
把阈值从 0.10 扫到 0.95，观察"自动分流比例—自动分流准确率"的曲线是否单调合理。

## 3. 集成时做的适配

1. **清洗前置**：新闻组帖子包含邮件头、签名、引用行与十六进制串，直接在原始文本上做 TF-IDF 会被
   签名噪声干扰；本项目在向量化前统一清洗，并在加载时就 `remove=("headers","footers","quotes")`。
2. **词表与模型解耦**：把 `TfidfVectorizer` 作为流水线的第一步固定下来，换分类器时词表不变，
   保证模型对比公平。
3. **置信度可用**：裸 `LinearSVC` 只有决策间隔，无法设阈值，因此最终模型加了 Sigmoid 校准。
4. **领域外兜底**：新增未登录词比例检查，比例超过 45% 时直接转人工，避免把与训练分布无关的文本
   硬塞进 20 类。
5. **可解释层**：复用词频统计自建"关键词证据库"（对数几率比），为每条结论给出命中的判别词，
   弥补线性模型"只给标签"的短板。
6. **异常处理**：模型文件缺失、JSONL 字段缺失、空文本都给出明确中文提示并走复核，不静默失败。
